# ЛР1 — Nginx, HTTPS и два backend

В этой работе Nginx обслуживает статический интерфейс и принимает API-запросы, распределяя их между двумя экземплярами Flask. В Compose оба backend подключены к общей сети frontend/database; PostgreSQL остаётся отдельным сервисом из ЛР0/ЛР2.

## Локальный запуск

Текущая версия использует [единый быстрый запуск проекта](../../README.md#быстрый-запуск): он создаёт `.env`, локальные TLS/Basic Auth файлы, поднимает Compose и указывает HTTPS URL. Это также исключает ситуацию, когда команды ЛР1 запускаются без `.env`, нужного Compose.

## Что проверяется

```sh
./scripts/lab-01-check.sh
./scripts/lab-01-dns-check.sh
```

Первый скрипт проверяет редирект HTTP→HTTPS, появление обоих значений `X-Backend-ID`, `/docs/` с `alias`, выдачу разного содержимого по `app.local` и `companion.local`, собственные 404-страницы, Basic Auth, разрешённые публичные файлы в `/assets/`, ответ 429 на короткий burst запросов и доступность API при остановке `backend2`. После теста второй backend запускается обратно. Второй скрипт в собственной временной сети меняет backend IP и проверяет, что Nginx узнаёт его без reload; скрипт удаляет созданные им контейнеры и сеть.

Точки настройки: [Nginx](../../docker/lab-01/nginx.conf), [Compose](../../compose.yaml), [идентификатор backend](../../app/backend/server.py). Секреты TLS/Basic Auth создаются скриптом в `.local/nginx/`, исключённом из Git.
