# ЛР1* — три ошибки конфигурации Nginx

Отдельный локальный стенд воспроизводит path traversal через `alias`, листинг каталога и выдачу dotfile. Проверка должна обнаружить все три заранее подготовленные ошибки.

Запуск из корня проекта:

```sh
./scripts/lab-01-star-check.sh
```

Скрипт создаёт собственную сеть и контейнер Nginx, публикует порт только на `127.0.0.1:18081`, делает три запроса к фиктивным файлам и удаляет свои контейнер и сеть. Конфиг не подключён к основному Compose; настоящих паролей или API-ключей в fixtures нет.

Для основного сервиса `/.env` должен быть закрыт. Здесь ожидается HTTP 200 с тестовой строкой. Если по привычке добавить запрет, скрипт пожалуется — у него украли уязвимость. Исправления применяются к рабочей конфигурации, а этот образец нужен, чтобы плохое поведение можно было воспроизвести и распознать.
