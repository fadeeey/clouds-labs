# ЛР1* — локальный стенд

Запуск трёх проверок:

```sh
./scripts/lab-01-star-check.sh
```

Скрипт создаёт отдельную сеть и контейнер Nginx, публикует порт только на `127.0.0.1:18081`, выполняет три запроса к учебным фиктивным файлам и затем удаляет контейнер и сеть. Nginx-конфиг специально содержит три ошибки и не используется основным Compose. В fixtures нет реальных паролей или API-ключей.
